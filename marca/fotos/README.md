# Biblioteca de fotografias (reserva)

Só é usada quando as APIs do Pixabay/Pexels não estão disponíveis. Organizar por serviço:
`erp/`, `websites/`, `apps/`, `suporte/`, `consultoria/`, `geral/`.

Regras: fotos com licença livre para uso comercial (Pixabay, Pexels, Unsplash), sem logótipos/marcas visíveis,
nunca fotos de clientes ou projetos reais. JPG com pelo menos 1080 px no lado menor.
