# Biblioteca de fotografias (reserva)

Só é usada quando a API do Pexels não está disponível. Organizar por serviço:
`erp/`, `websites/`, `apps/`, `suporte/`, `consultoria/`, `geral/`.

Regras: fotos com licença livre para uso comercial (Pexels, Unsplash), sem logótipos/marcas visíveis,
nunca fotos de clientes ou projetos reais. JPG com pelo menos 1080 px no lado menor.
